## 修复

- **macOS CI 打包**：改为只构建 `.app`（`tauri build --bundles app`），再用系统 `hdiutil` 生成 DMG，移除 `create-dmg` 及其 Finder/AppleScript 依赖，修复无图形会话的 macOS runner 上反复失败的问题。
- 为 `tauri build`、updater 签名和 Release 资产上传增加重试；`codesign` 的 hardened runtime 失败时回退到普通 ad-hoc 签名。
- 应用功能与 v1.10.5 相同（线路选择/浅色主题/演示数据移除/详情选集修复）。

## 说明与限制

- 本版主要用于验证 macOS 流水线与补齐 macOS 资产；Android APK 功能与 v1.10.5 一致。
- 若 macOS 仍失败，下一步需要 Actions 原始日志定位到具体命令。
- Android 后台播放与原生安装仍待真机复测。
