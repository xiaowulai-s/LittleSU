## 改进

- **真实缓存清理**：设置 → 数据的「清理缓存」现在会清空标题、豆瓣、节目单内存缓存与 Cache Storage，不再只是提示。
- **搜索范围更实在**：「全部」只统计并搜索可用的采集源，3 个返回网页的 HTML 占位源不再拖慢搜索。
- **精简客户端目录**：移除 `apps/app/public` 旧静态界面与 Tailwind 构建脚本，前端只保留 `ui-next`（旧实现可从 git 历史检出）。
- **发布说明自动化**：Release 正文改由 `docs/releases/<tag>.md` 提供，本版本起生效。

## 校验

- 每个资产提供 `SHA256SUMS`，桌面端自动更新清单 `latest.json` 覆盖 Windows / Linux / macOS。
- 桌面更新包均以 updater 公钥校验，客户端启用 `requireSignedVersion`。
