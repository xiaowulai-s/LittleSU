## 新增

- **搜索分页 / 加载更多**：搜索结果页底部新增「加载更多」，按源接口的页码参数请求下一页并合并去重；单源搜索与本地示例数据不分页。
- **同源多线路切换**：解析 `vod_play_from` / `vod_play_url` 中的 `$$$` 多线路，详情页与播放器均可切换线路；播放器顶栏显示当前线路名，切换线路会重置当前集与播放进度。
- **收藏 / 历史详情补全多源**：从收藏或历史进入详情时，若条目没有换源列表，会在前 4 个已启用源按片名回查，自动补全换源与相关推荐；查询失败不影响详情正常加载。

## 修复

- **剧集重复显示**：同一源返回多条播放线路时，此前会把各线路剧集拍平拼接（20 集显示成 1–20 集后又重复一遍，共 40 集）；现在按线路拆分，只展示当前线路的剧集，并可在详情页与播放器切换。

## 说明与限制

- 分页优先跟随接口返回的 `pagecount` / `total_pages`；源未提供分页信息时，只要本页有新增内容就允许继续加载，最多 20 页、结果上限 500 条。
- 线路切换只在同一部影片的同一采集源内生效；跨采集源请使用「换源」。
- 收藏 / 历史的多源补全最多并发查询 4 个已启用源，未命中时保留原条目。
- HTML 实验源（黑木耳 / 卧龙 / 华为吧）接口仍被拦截或失效，仅保留占位且不参与搜索。
