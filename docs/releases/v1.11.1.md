## 修复

- **手机端纵向亮度/音量手势**：全屏和非全屏都可以在播放画面上上下滑动调节；左右分区改为按播放画面宽度计算，横屏分栏时右侧滑动不再误判为亮度。
- **Android 系统音量/亮度**：安卓 WebView 不支持可靠修改 `video.volume`，改为通过原生桥调用 `AudioManager` 调节媒体音量、通过窗口属性调节亮度；手势 HUD 显示系统当前音量/亮度百分比，退出播放页恢复系统亮度。
- **直播页手势**：直播画面同样支持左侧上下滑调亮度、右侧上下滑调音量，与点播页一致。
- **手机端投屏入口**：Android 始终显示投屏按钮；WebView 不支持 Remote Playback 时打开系统投屏设置（屏幕镜像），浏览器仍使用 Remote Playback 设备选择。
- **手势分区**：点播页左右双击、亮度/音量分区改为相对视频画面计算，避免非全屏侧栏布局下左右颠倒。

## 说明与限制

- Android 的投屏入口当前拉起系统投屏设置；应用内 DLNA/Chromecast 设备列表仍未接入，后续版本补原生投屏。
- 横屏旋转由 CSS 兜底的竖屏全屏下仍不启用手势，旋转到横屏后生效。
- 其余功能与 v1.11.0 相同：直播台标/跨源收藏与故障转移、字幕样式/偏移、双击/长按手势、首页刷新。
