## 新增

- **画中画**：支持的平台可在播放设置里切到系统画中画窗口；不支持的环境自动隐藏入口。
- **锁屏防误触**：全屏下可锁定控制条，只保留解锁按钮；返回键 / Esc 也先退出锁定。
- **亮度 / 音量手势**：全屏时左侧上下滑调亮度（30%–160%），右侧上下滑调音量，居中显示百分比并保存音量。
- **画面比例**：自适应 / 填满两种模式，切换立即生效。
- **字幕与音轨**：读取当前源提供的字幕、音轨列表并可切换；源未提供时明确提示。
- **全屏选集面板**：播放设置里直接选集，全屏状态下也能换集。

## 修复与改进

- 前端现在正式打包 **hls.js**（此前代码只检测全局 `window.Hls`，实际未加载，只能依赖系统原生 HLS）；Windows / Android 的 HLS 播放与字幕/音轨信息更可靠。
- 播放设置面板改为整页底部弹层，小屏时不再被视频区域挤压。
