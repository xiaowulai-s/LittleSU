## 新增

- **自定义源启停 / 单源测活**：每个源行可单独测活；自定义点播源支持启用开关，停用后不参与搜索与批量测活。
- **外挂字幕**：播放设置可加载本地 `.srt` / `.vtt`，自动转 WebVTT 并挂到播放器；可随时移除。
- **自定义直播源**：设置 → 数据源支持新增/编辑/删除/启停 M3U、TXT 订阅，直播页即时出现对应频道源。
- **投屏入口**：支持 Remote Playback 的环境会出现「投屏」按钮，可唤起系统设备选择；直播页同样支持。
- **Android 更新直达 APK**：更新提示与设置页直接打开 Release 的通用 APK 下载地址，不再先跳 Release 页面。
- **桌面快捷键**：新增 `↑` / `↓` 调音量、`M` 静音；原有空格、`←` / `→`、`F`、`Esc` 保持不变。
- **界面密度生效**：紧凑 / 舒适 / 大屏会真实调整首页轨道宽度与搜索结果网格。

## 说明与限制

- 投屏依赖 WebView 的 Remote Playback 与同网设备，不支持的环境不显示入口。
- 外挂字幕需每次播放手动加载，不跨会话保存。
- Android 更新仍是「下载 APK 后由系统安装确认」，未接入原生静默安装。
- HTML 实验源（黑木耳 / 卧龙 / 华为吧）接口被拦截或已失效，仍保留占位且不参与搜索。
