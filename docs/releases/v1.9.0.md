## 新增

- **过期签名 m3u8 自动重解析**：播放失败若属于 401/403、清单/分片加载失败或超时，会先回源重新拉取详情，按线路名与剧集名定位当前集的新地址后自动重载；手动点「重试」同样先刷新地址，不再反复请求同一个过期链接。
- **单源搜索超时 / 重试配置**：设置 → 数据源 → 搜索请求，可选单源超时 8 / 12 / 20 / 30 秒与失败重试 0 / 1 / 2 次；搜索命令支持传入超时，配置保存在本机。
- **原生播放错误入口**：非 hls.js 的系统原生播放失败也会显示错误与「重试」，不再只有 HLS 错误可见。

## 说明与限制

- 自动重解析依赖源站详情接口本身可用；详情也获取失败时会回落到自动换源或错误提示。
- 为防循环，同一集每次进入只自动重解析一次；手动重试可再次触发。
- 搜索超时/重试只作用于搜索结果页的单源请求；收藏/历史的多源补全与源测活仍使用内置超时。
- 开启重试后，失败源的等待时间会变长（约为超时 × 尝试次数），默认不重试。
