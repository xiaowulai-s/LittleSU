## 修复

- **全屏纵向亮度/音量**：移除全屏旋转保护对手势层的阻断；竖屏进入全屏并使用 CSS 旋转兜底时，滑动也能触发 HUD 和亮度/音量调节。
- 进入全屏、旋转屏幕或窗口尺寸变化时主动刷新横竖屏状态，避免 `portrait` 状态滞后导致全屏手势被跳过。
- 非全屏手势保持原有行为。

## 说明

- v1.13.0 的豆瓣详情、EPG、原生 DLNA、Chromecast 已在真机通过；本版只修复全屏纵向手势。
- 全屏旋转兜底时若未旋转手机，画面仍为侧向；建议旋转到横屏使用。
