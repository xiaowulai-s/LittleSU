## 新增

- **跳过片头 / 片尾**：
  - 播放设置面板新增“片头结束 / 片尾开始 / 清除跳过”。
  - 播放到片头结束位置后自动跳到标记点；播放到片尾开始位置时自动下一集（关闭自动连播时暂停）。
  - 标记按片名保存在本机；设置新增“自动跳过片头/片尾”开关。
- **手动画中画**（Android）：
  - 播放设置面板新增“画中画”按钮，直接进入 16:9 系统画中画；原有的按 Home 自动 PiP 保留。
  - 需要视频正在播放；桌面端继续使用浏览器/系统 PiP。

## 说明与限制

- 片头/片尾标记按片名保存，同一部剧的各集共用；不同集时间轴差异较大时建议先清除再重新标记。
- 自动跳过需要视频已加载出时长；片头标记需播放几秒后设置，片尾标记需在片尾开始前设置。
- 本版包含 v1.13.1 的全屏纵向手势修复。
