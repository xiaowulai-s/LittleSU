## 修复

- **更新入口统一**：顶部更新提示与设置页的「下载并安装」都走 Android 原生下载/安装，不再默认跳浏览器打开 Release 页面。
- **修复「解析包错误」**：只接受真正的 `.apk` 资产地址；发布早期 APK 尚未上传时会重新检查更新，不再把 Release 网页当作安装包下载成 `.apk`。
- **下载后校验**：DownloadManager 完成后检查文件存在、大小、包名与 APK 结构，有效才拉起系统安装器；下载失败或文件无效时自动打开浏览器下载页并提示。
- **下载稳定性**：每次使用唯一文件名避免重复文件冲突，请求附带浏览器 UA 与 `Accept: application/octet-stream`，并允许移动网络/漫游。

## 说明与限制

- GitHub Release 的 APK 地址会 302 到 CDN，DownloadManager 会正常跟随；若个别网络/代理把文件替换成网页，校验会识别并回退浏览器。
- 若浏览器下载后仍提示解析包错误，请核对 `SHA256SUMS` 中的 APK 摘要，或换网络重试。
- v1.10.1 的后台播放与通知进度修复继续包含在本版，仍待真机复测。
