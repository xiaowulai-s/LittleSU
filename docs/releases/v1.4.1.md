## 修复与改进

- **macOS 应用内更新**：更新包改为在 ad-hoc 签名后重建并重新签名，更新后的应用与 DMG 安装一致。
- **更新清单覆盖 macOS**：发布收尾作业把 `darwin-aarch64` 合并进 `latest.json`，Windows / Linux / macOS 都能收到更新。
- **全资产校验和**：`SHA256SUMS` 现在覆盖 APK、桌面安装包、更新包与 standalone 包。
- **签名版本绑定**：客户端开启 `requireSignedVersion`，拒绝签名版本与清单版本不一致的产物。
