## 亮点

- **豆瓣推荐**：首页新增热门 / 高分电影与剧集榜单，点击片名直接到已启用源搜索可播放地址。
- **自定义源**：设置 → 数据源可新增、编辑、删除苹果 CMS 接口，保存后立即参与搜索、详情与测活。
- **搜索范围联动**：推荐源 / 全部 / 测活可用 三种范围真正决定请求的源集合，计数动态更新；返回网页的实验源不再参与批量搜索。
- **详情换源**：同一影片聚合到多个源时，可在详情页切换并重新拉取该源剧集。
- **Android 硬件返回键**：优先回退路由，根页面才退出应用。
- **直播节目单**：按频道加载 51zmt 节目单，显示今天 / 明天的节目与正在播、下一档。
- **测活自动停用**：测活失败的已启用源会自动取消勾选，减少无效等待。
- **缓存清理**：设置 → 数据可真正清理内存缓存与缓存分区。
