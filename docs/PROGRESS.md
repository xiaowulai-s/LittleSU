## 验收流程

1. `cd apps/app/ui-next && npm test && npm run build`
2. `cd apps/app/src-tauri && cargo check --locked`
3. 生产构建后跑 `.legacy-backup/qa-v170.mjs`（390×844 移动视口 + 1440×900 桌面视口）
4. 推送 `v*` 标签，等待 `app-release` / `web-standalone` / `web-docker` 三条流水线
5. 校验 `latest.json` 版本、签名内嵌版本、`SHA256SUMS` 与 APK digest、GHCR 多架构清单
6. Android 原生功能（后台播放/APK 安装）需在真机补一次验收
